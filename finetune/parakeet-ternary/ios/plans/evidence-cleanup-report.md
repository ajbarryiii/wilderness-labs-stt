`g0probe.py`, and `tests/compare_manifests.py`. These were migrated together with

checks size and SHA-256 before returning original bytes, publishes full records
outside Git and writes only summaries/index into Git. Indexed enumeration prevents
withdrawn or stray display files from reappearing as evidence.

before eligibility and prerequisite checks. CLI checks flow through those shared readers.

in [../README.md](../README.md#evidence-storage-and-verification). The initial bundle
was exported on Linux and imported on the Mac; all 673 entries and projections
verified on both. Missing full data has no repository fallback.
