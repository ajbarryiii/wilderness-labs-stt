DESIGN (for V/T to borrow): Firestorm per Dougall Johnson's tables: EOR, CNT, ADD, UADALP, UDOT (vector and by element), SDOT are all 1 uop at 4/cycle on the same 4 SIMD units (u11-14); LDR q is load-unit only (3/cycle); LD1R is 2 uops, one of them on a SIMD unit. So bit-serial needs >= 3 SIMD uops (EOR, CNT, accumulate) per 128 bit-products = 16 MACs, vs 1 SDOT: a hard 3x arithmetic handicap. P's default: K along the lanes (128 positions/step), weights and planes plain LDR q, and the accumulate is UDOT-by-element against a constant byte 2^r (CNT widen + plane weighting in 1 uop), one u32x4 per (output, frame-part); valid is folded into the stored operands (n = ~b & valid, zero planes past K), so no AND. Classic variant "uadalp": planes in u16 lanes, LD1R.8H weights, UADALP (3 + 1/F uops). Plane packing: LD4+UZP, 3-stage BSL bit transpose, ~60 uops per 128 bytes (<0.3% of a GEMM).

DESIGN
- Weights stay 1 bit ("v-layout", layout.rs): rows in groups of 4, inputs in chunks of 32; chunk = 16 B, byte 4nl+kl bit j = code(row 4g+nl, input 32c+4j+kl). Pure bit permutation for model shapes: codes = N*K/8 B exactly (MB1 75,497,472 B), scales 4N B (per_row). Ragged N/K only: zero-padded bits, plus (K%32 != 0 only) a zero-padded activation copy per slot.
- Expansion in registers, 1 SIMD op per 16 weights: CMTST(code vector, 1<<j) (CMLT #0 for j = 7) = SDOT operand of input quad 8c+j for the 4 rows as {0x00,0xFF} = -b. Exact: d = -2z - U (z = SDOT accumulator, U = Σ_k q per frame-part; |z|,|U| <= 128K in i32). Chosen by measurement over ±1 (CMTST+ORR, 16 ops/chunk) and {0,1} (AND / USHR+AND / USHR, 14 ops/chunk); all exact.
- Microtile 4 rows x R frame-parts, R = F*C <= 16 (i8x2: F <= 8 -> R = 16; i8x3: F <= 5 -> R = 15). Activations read in place from QuantizedActs [T][C][K] (no packing): one 16-B load per frame-part = 4 quads, by-element SDOT lane = quad, so each expanded vector feeds R SDOTs. Inline asm generated per R (build.rs); 4 base pointers with [b,K]/[b,2K]/[b,3K] register offsets and a post-index on each block's last load (no address arithmetic in the loop); row-major SDOT order.
- INNER LOOP (objdump of the shipped replay binary, panel::<2,8,16,false>), per 32 inputs: 128 sdot (by element) + 7 cmtst + 1 cmlt = 136 SIMD uops, 33 ldr q (1 code vector = 128 weights, 32 activation), subs + b.ne; 0 stack refs in the loop; masks v16-v22 set once per row group. Firestorm model (4 SIMD pipes, SDOT/CMTST 1 uop; ldr q on 3 load units): 34 cycles per 128 SDOT = 94.1% of SDOT peak, 0.97 loads/cycle. Throughput-bound iff R >= 4L-1 (8 dependent SDOTs per accumulator per chunk): L = 3.0 (P) / 3.8 (E) measured -> R >= 11 on P; timed T always gives R >= 12.
- Epilogue shared::epilogue::neon::finish4::<C> on d = -(2z + U); Out::Dots and Out::F32 = one routine kernel::panel::<C,F,R,DOTS> up to the store.
- Activation state per slot: U (+ ragged-K copy), rebuilt unless call.reuse on the same unchanged object (address + T/C/K checked), so K, V reuse Q's.
- Threads (default "auto"): frames only whenever every thread gets >= 1 full panel (all timed T at 4/8 threads), split_range over frames = the shared quantizer's split, so each thread multiplies the frames it just quantized and sums their U inside the same job: ONE pool.run per GEMM. Balanced panels (44 frames -> 8,8,7,7,7,7). Activation panel (16 KB at K=1024, 64 KB at K=4096) stays in L1 across all row groups; the call's weight bits (<= 512 KB) stream from L2. Small T falls back to frames x groups grids (separate U pass). Workspace: U only (rows*C*4 B per slot), no tiles.
- Tuning grid v_sdot::GRID (4 points, JSON for KernelConfig.tuning): split {auto, groups} x (fmax2, fmax3) {(8,5), (6,4)}; point 0 = default = Null. Every point passes the contract (tests/grid.rs, P's preset pattern).
